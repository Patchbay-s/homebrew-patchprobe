# PatchProbe Homebrew tap

Install the Apple silicon pre-release:

```sh
brew tap Patchbay-s/patchprobe
brew install --cask patchprobe
```

This cask installs the same unsigned, not-notarized `v0.1.0` DMG published by
[PatchProbe](https://github.com/Patchbay-s/PatchProbe/releases/tag/v0.1.0).
On first launch, Control-click `PatchProbe.app` in Finder, choose **Open**, and
confirm the prompt. Intel builds and signed releases are not available yet.
