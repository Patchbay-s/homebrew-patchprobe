# PatchProbe Homebrew tap

Install [PatchProbe](https://github.com/Patchbay-s/PatchProbe) for Apple silicon:

```sh
brew tap Patchbay-s/patchprobe
brew install --cask patchprobe
```

The cask installs the
[latest release](https://github.com/Patchbay-s/PatchProbe/releases/latest) DMG, signed with an
Apple Developer ID and notarized. On the first scan, allow **Local Network** access when macOS
asks. Intel builds are not available yet.
